# Esdras Santos

Fullstack developer, mostly backend these days: APIs, session handling, caching, the parts nobody screenshots.

## Things I've built

[Zipway](https://github.com/esdrassantos06/zipway) is a URL shortener with a Next.js frontend and two backends I wrote at different times, [one in FastAPI](https://github.com/esdrassantos06/zipwayAPI) and [one in Go with Fiber](https://github.com/esdrassantos06/shly-backend-go). The Go one validates Better Auth sessions against a local cache, then Redis, then Postgres.

[Tarevity](https://github.com/esdrassantos06/tarevity) is a task manager on Next.js and Prisma. [skills-installer](https://github.com/esdrassantos06/skills-installer) is a desktop GUI for installing agent skills in batch, because running `npx skills add` once per skill got old fast. [My site](https://github.com/esdrassantos06/portfolio-esdras) is Next.js and Tailwind.

## Tools

TypeScript and Go carry most of the work. React and Next.js on the frontend, Tailwind with shadcn/ui for styling, occasionally Vue or Electron. Backend: Fiber, NestJS, FastAPI, Postgres, Redis, Supabase when I don't feel like running a database, Docker when I do.
